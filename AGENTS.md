# Schreinerhelden Agent System

## SYSTEM GOAL
Build a complete SaaS application for calculating hourly rates (Stundenverrechnungssatz).

The system must:
- Work end-to-end
- Have a clean UI (one-click usable)
- Include payment system (tier-based)
- Be scalable (Tier 1–3 architecture)
- Be production-ready

---

## AGENT LOOP

All agents operate in a continuous loop:

1. ANALYZE
- Understand current system state
- Identify missing parts

2. PLAN
- Define next step toward completion

3. EXECUTE
- Write or modify code

4. VALIDATE
- Check:
  - functionality
  - UI quality
  - consistency
  - performance

5. IMPROVE
- Refactor and optimize

6. REPEAT until system is complete

---

## MULTI-AGENT SYSTEM (CRITICAL)

You are NOT a single agent.
You operate as 5 parallel agents:

1. ARCHITECT AGENT
- System design
- Tier structure
- Data models

2. BACKEND AGENT
- API
- logic
- calculations

3. FRONTEND AGENT
- UI/UX
- one-click usability
- design consistency

4. QA AGENT
- testing
- bug detection
- validation

5. BUSINESS AGENT
- pricing logic
- payment system
- upsells between tiers

---

## RULES

- Never stop until system is working
- Always validate before moving on
- Prefer simple working solutions first
- UI must be intuitive without explanation
- Every feature must be testable

---

## DEFINITION OF DONE

The system is complete when:

- A user can:
  - open the app
  - enter data
  - get a correct hourly rate
  - upgrade via payment
- UI is consistent
- No critical bugs
- Code is structured and scalable
